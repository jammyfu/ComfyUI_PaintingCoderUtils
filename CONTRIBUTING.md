# Contributing to ComfyUI Painting Coder Utils / 参与贡献

Thanks for helping! 欢迎参与。

1. Open an issue first for larger changes (bug / feature templates are provided). 较大的改动请先开 issue。
2. Fork, create a branch, keep each PR focused on one change. 每个 PR 只做一件事。
3. Run locally before submitting / 提交前本地验证：

```bash
# copy into ComfyUI/custom_nodes, restart ComfyUI and load a workflow from workflows/
```

4. Describe what changed and how you tested it in the PR template. 在 PR 模板里写清改了什么、怎么测的。

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md). 参与即表示同意[行为准则](CODE_OF_CONDUCT.md)。
