# Security Policy / 安全策略

## Reporting a vulnerability / 报告漏洞

Please **do not** open a public issue for security problems. Report privately via GitHub Security Advisories:
请不要用公开 issue 报告安全问题，请通过私密渠道提交：

https://github.com/jammyfu/ComfyUI_PaintingCoderUtils/security/advisories/new

We aim to respond within 7 days. 我们会尽量在 7 天内回复。

## Supported versions / 支持的版本

Only the latest release and the default branch receive fixes. 只修复最新版本和默认分支。
